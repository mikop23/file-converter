파일 변환기 (Windows)

[버전 두 가지]
  - 오프라인 버전: 인터넷 없이 PC 안에서만 동작. 내장 AI(처음 한 번 1.1GB 다운로드)
  - 온라인 버전: 더 똑똑한 온라인 AI(Claude) + 사진·스캔 PDF 글자 추출
    (말로 시키기·글자 추출 때 요청 문장/파일 내용이 서버로 전송됨)

[실행]
  FileConverter.exe 더블클릭. 파이썬 설치 필요 없음.
  처음 실행 때 "Windows의 PC 보호" 창이 뜨면 → "추가 정보" → "실행"
  (서명 안 된 개인 제작 프로그램이라 뜨는 경고)

[사용법]
  - 왼쪽에 파일/폴더를 끌어다 놓기 (끌어서 순서 변경, Delete 키로 삭제)
  - 버튼: 이미지 묶기(PDF/Word/PPT/ZIP), 문서 변환, PDF → 이미지
  - 말로: "사진 시간순으로 pdf로 묶어줘" 입력 후 엔터
  - 같은 이름 파일이 있으면 '묶음 (1).pdf'처럼 따로 저장

[Word·PPT·엑셀 → PDF]
  - PC에 MS 오피스가 있으면 그걸로 바로 변환 (따로 설치 필요 없음)
  - 오피스가 없으면 변환할 때 'LibreOffice 자동 설치'를 물어봄 → '예' 누르면 끝

[AI로 말 알아듣기]
  - 오른쪽 위 'AI 받기' 버튼 → 약 1.1GB 한 번만 받으면 끝
  - 받은 뒤엔 인터넷 없이 이 PC 안에서만 돌아감
  - Ollama를 이미 쓰고 있으면 그걸 우선 사용 (더 큰 모델 가능)

[글자 추출 - 온라인 버전만]
  - 사진이나 스캔 PDF를 넣고 '글자 뽑기' → Word/텍스트/마크다운으로 저장
  - 표는 표로, 제목은 제목으로 최대한 살려줌
  - 서버 주소가 비어 있으면 오른쪽 위 '서버' 버튼으로 입력
